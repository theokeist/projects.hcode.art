# projects.hcode.art

Katalog webových aplikací a interaktivních modulů ekosystému **HCODE.ART**.

## Obsah projektu
- **HCODE Landing & Hub (`index.html`)**: Hlavní interaktivní rozcestník webových aplikací a prezentace projektů.
- **Čínština: Vztahová síť znaků (`app/`)**: Interaktivní webová aplikace pro studium a rozbor čínštiny – síť znaků Hanzi, všech 204 moderních radikálů se slovní zásobou, vizuální paměťové emoji kotvy a vyhledávač.
- **Korejština: Kompletní Hangul & Slovník (`korean/`)**: Plnohodnotná interaktivní webová aplikace pro studium korejštiny a písma Hangul – 40 hlásek (19 souhlásek, 21 samohlásek a dvojhlásek), 7 pravidel pro koncové souhlásky Batchim a fonetickou asimilaci, sino-korejská i rodilá čísla s počítadly, konverzační fráze s rozborem po tokenech, 32 ucelených gramatických modulů (nepravidelnosti ㅂ/ㄷ/ㅡ/르/ㅅ, honorifika 높임말, podmínky a modality), 350+ slovník s emoji kotvami a interaktivní proud autentických online textů (KBS News, Yonhap, VisitKorea, tradiční přísloví 속담) s audio výslovností (Web Speech API).
